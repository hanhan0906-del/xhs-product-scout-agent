## 2. 只读 SQL 口径

### 2.1 主集合

主集合先用相关子查询取每个商品最新一条评估，再限定：

```sql
WITH latest_assessment AS (
  SELECT a.*
  FROM candidate_assessments a
  WHERE a.id = (
    SELECT a2.id
    FROM candidate_assessments a2
    WHERE a2.product_id = a.product_id
    ORDER BY a2.id DESC
    LIMIT 1
  )
)
SELECT *
FROM latest_assessment
WHERE status IN ('candidate', 'needs_review');
```

观察字段同样只取该商品 `observations.id DESC` 的最新一条。不能把旧观察的指标条替代当前观察，也不能把历史任意一条 `candidate` 覆盖最新状态。
